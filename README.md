# 생태계 보전 게임 프롬프트 만들기

초등학교 4학년 과학 `생물과 환경` 수업에서 학생이 생태계 보전 게임을 계획하고, 캔바 AI에 붙여 넣을 제작·수정 프롬프트를 만드는 웹앱입니다.

## 학생 활동

1. 게임 이름, 장소, 생물, 쓰레기, 생태계 보전 메시지를 정합니다.
2. 게임 시간, 레벨 상승 기준, 쓰레기 등장 간격을 고릅니다.
3. 그림 분위기와 특별한 기능을 정합니다.
4. 완성된 문장을 복사하여 캔바 AI의 코드 대화창에 입력합니다.
5. 게임을 직접 해보고 친구 의견을 받아 수정 요청을 만듭니다.

게임을 실제로 생성하는 기능은 캔바 AI에서 사용합니다. 이 앱은 작성한 계획을 바탕으로 요청 문장을 정리합니다.

## 실행과 배포

빌드와 설치가 필요 없는 정적 웹앱입니다. Firebase, 계정 로그인, API 키가 필요하지 않습니다. 학생들의 계획은 각 브라우저에 따로 저장됩니다.

### GitHub와 Vercel

배포용 ZIP에 들어 있는 `index.html`, `styles.css`, `app.mjs`, `core.mjs`, `assets` 폴더를 GitHub 저장소의 최상위에 올립니다.

Vercel에서 해당 저장소를 연결합니다.

- Framework Preset: Other
- Build Command: Override를 켜고 비워 두기
- Output Directory: 비워 두기 또는 `.`
- Environment Variables: 없음

설정 참고: https://vercel.com/docs/builds/configure-a-build

개발 원본에서 배포한다면 `dist` 폴더를 배포 루트로 지정합니다. 동봉된 배포용 ZIP은 `dist`의 내용을 최상위에 담고 있습니다.

### 로컬 확인

프로젝트 루트에서 정적 웹 서버로 `dist`를 제공하세요. 예를 들어 `python3 -m http.server 8000 --directory dist`로 실행하고 `http://localhost:8000`에 접속할 수 있습니다. 자바스크립트 모듈을 사용하므로 파일을 더블클릭하는 대신 HTTP 서버를 사용합니다.

## 파일 저장과 이어 쓰기

- 입력한 계획은 같은 브라우저에 자동 저장됩니다.
- 우측 상단 메뉴에서 계획 파일을 JSON으로 저장하고 다시 불러올 수 있습니다.
- 제작 프롬프트와 수정 프롬프트는 각각 TXT로 다운로드할 수 있습니다.
- 브라우저 데이터를 지우거나 다른 기기로 옮기려면 먼저 계획 파일을 저장합니다.
- 캔바 사용 가능 기능과 학생 권한은 수업 전에 확인합니다.

## 디자인과 접근성

태블릿 가로 화면을 우선으로 구성했으며 작은 화면에서는 세로로 재배치됩니다. 키보드 이동, 입력 오류 안내, 읽기 쉬운 대비, 움직임 줄이기 설정을 지원합니다.

배경은 이 수업을 위해 생성한 AI 일러스트입니다. 오염도와 레벨은 학습을 위한 게임 규칙이며 실제 생태계 수치를 뜻하지 않습니다.
